# Community conduct

Treat contributors with respect. Critique code and ideas with specific evidence.
Welcome newcomers and explain requested changes clearly. Harassment, discrimination,
threats, doxxing, personal attacks and posting private credentials/data are unacceptable.

Keep issues and pull requests relevant to the project. Credit others' work and
preserve licenses. Do not spam, invent test results or claim unsupported capabilities.

Maintainers may edit/remove inappropriate content, close disruptive threads or limit
participation. Report concerns privately to the repository owner through an available
GitHub private channel; do not publish personal details in a report. Apply these
expectations across the repository's issues, discussions and reviews.
